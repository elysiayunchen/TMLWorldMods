# TMLWorldMods

**泰拉瑞亚 tModLoader 小工具：按世界自动切换 Mod 组合。**

玩 tModLoader 时，不同的世界往往依赖不同的 mod 集合——灾厄世界要灾厄全家桶，其他世界又是另一套。游戏本体只能全局开关 mod，每次换世界都得手动进 mod 列表折腾一遍。这个工具把这件事自动化了：**选世界 → 点启动，mod 自动切换；退出游戏自动恢复原状。**

## 功能

- **世界列表自动扫描**：自动定位 tModLoader 存档目录，列出所有世界
- **自动提取 mod 集**：直接解析世界数据文件（`.twld`）中的 `usedMods` 记录——和游戏弹窗对比的是同一份数据，含不写世界数据的依赖库，选中世界即可看到它需要的完整 mod 清单
- **一键启动**：写入该世界的 mod 集 → 拉起 tModLoader → 游戏退出后自动结算
- **退出后三档策略**：回写为该世界配置（游戏内改动也会同步）/ 恢复启动前状态 / 不处理
- **联机保护**：检测到联机会话（自己开服或连接服务器）时，退出后强制恢复启动前状态，不污染任何本地世界配置
- **手动自由度**：随时手动编辑某世界的 mod 集、手动应用/恢复；写入前自动备份 `enabled.json`
- **单实例锁**：防止多开互相覆盖配置
- **内置体检**：高级窗口一键生成健康报告（环境探测 / mod 识别 / 全部世界解析 / 启用集一致性），排查问题不用进游戏试探
- **可移植**：单文件 exe，拷到任何 Windows 机器双击即用；Steam 未运行会自动拉起，`steam://` 协议异常时自动改走启动脚本，路径扫不到时主动引导手动指定

## 下载

到 [Releases](../../releases) 下载 `TMLWorldMods.exe`，双击即用（免安装、零依赖）。

> 需要已安装 tModLoader（Steam 版最佳）。把 exe 旁边的 `TMLWorldMods.json` 一起拷走，可以把调好的「世界 → mod 集」配置带到新机器。

## 三步上手

1. 左边点选一个世界（自动读取它需要的 mod）
2. 点「▶ 启动」（或直接双击世界名）
3. 正常游玩，退出游戏后自动处理，不用管

## 工作原理

tModLoader 的 mod 启用集由存档目录下 `Mods/enabled.json` 决定，而每个世界上次保存时使用的 mod 清单记录在世界数据（`.twld`，gzip 压缩）的 `usedMods` 节里。本工具：

1. 启动世界前，解析该世界 `.twld` 的 `usedMods`，写入 `enabled.json`（原文件备份为 `.bak`）；
2. 通过进程监听等待游戏退出；
3. 按所选策略结算（回写 / 恢复 / 忽略），联机会话强制走"恢复"。

工具只读写 `enabled.json` 和自己的配置文件，不修改游戏本体与世界文件。

## 常见问题

**启动后还弹「缺少/增添 mod」提示？**
一般是 `.twld` 里的 `usedMods` 引用了本机未安装的 mod。工具体检报告会列出所有世界引用但未安装的 mod；装上它们或进游戏点一次"继续"重存世界即可永久收敛。

**Steam 没开能启动吗？**
能。`steam://` 协议会自动拉起 Steam；协议损坏时自动改走 tML 安装目录的 `start-tModLoader.bat`。

**联机（服务器在别人电脑）怎么办？**
正常连就行。服务器世界的 mod 同步由 tML 自带机制处理；本工具检测到联机会话后，退出时只恢复你的本地状态，不会把服务器的 mod 集写进世界配置。

**换电脑能用吗？**
能，exe 单文件绿色版。配置跟着 exe 走（同目录 `TMLWorldMods.json`）。

## 本地构建

依赖：Python 3.9+（需 tkinter）、PyInstaller。

```bash
pip install pyinstaller
pyinstaller -F -w -i app.ico -n TMLWorldMods tml_world_mods.py
```

测试：

```bash
python test_smoke.py   # 冒烟测试（使用临时存档，不碰真实数据）
python test_mutex.py   # 单实例锁跨进程测试
```
